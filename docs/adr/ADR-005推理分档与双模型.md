# ADR-005: 优化③④——推理分档与双模型分层（默认关，未验证）

状态: 已实现、未验证 | 日期: 2026-09-14

③ 推理分档：`reasoning_tier` 开启时，≤15m 周期阶段一 effort 降为 medium。
④ 双模型：`dual_model` + `model_light` 配置后，阶段一走轻模型。

## 未验证原因

- ③ 只作用于 ≤15m 周期；冻结样本为 30m，测不出差异（需另行冻结 15m 样本）
- ④ 需要配置真实的 `model_light`（当前为空，轻模型回退主模型，
  质量轮回退为第二组噪声对照，数据归入 ADR-002）

## 启用条件

用户提供轻模型端点/名称并接受「阶段一诊断质量可能变化」后，
配置 `llm_opt.model_light` 并单独跑一轮质量对比。

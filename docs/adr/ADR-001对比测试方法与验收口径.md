# ADR-001: LLM 优化的对比测试方法与验收口径

状态: 已接受 | 日期: 2026-09-13 | 分支: llm-opt

## 背景

两阶段分析单轮实测消耗 186,688 tokens（输入 175,023 + 输出 11,665）、耗时 50–70 秒。
计划实施四项优化：① K 线特征表瘦身（K11+ 压缩）、② 静态内容前置重排、
③ 推理分档（≤15m → medium）、④ 双模型分层（阶段一轻模型）。

用户要求"保证优化不改变分析的结果"。但当前配置开启深度思考（effort=high），
请求不传 temperature，模型输出天然非确定——同一分支跑两次文本也不同。
因此"结果完全不变"不可定义、不可验收。

## 决策

1. **验收口径 = 决策级等价 + 容差**（问题 1，选项 A）：
   - 完全一致字段：`gate_result`、`cycle_position`、`order_direction`、`order_type`、置信度档位
   - 容差字段：`entry_price` / `stop_loss_price` / `take_profit_price`（±0.5%）
   - 通过线：一致率 ≥ 95%，且每个不一致个案人工归因复核
     （归因两类：「摘要压缩丢失关键信息」= 优化缺陷；「LLM 随机摆动」= 可接受噪声）

2. **分层验收**（问题 2，选项 A）：③④ 本质改变输出，谈等价无意义。
   - 等价轮：仅开 ①②（③④ 关）vs main 基线 → 按 1 验收
   - 质量轮：分别单独开 ③、④ vs main → 输出一致率 / 耗时 / token 三维报告，
     由用户拍板是否默认开启

3. **冻结回放**（问题 3，选项 A）：20 支样本（沪主板 6 / 深主板 4 / 创业板 3 /
   科创板 3 / ETF 2 / 港股 2），30 分钟周期 × 100 根，快照存
   `data/fixtures/llm_opt/`。两分支读同一份冻结数据，消除行情漂移。
   选 30m：K10–K1 逐棒窗口信息密度最高，对「K11+ 摘要压缩」最敏感。

4. **单分支 + ADR**（问题 4，选项 A）：`llm-opt` 分支，四项各带配置开关
   （①② 默认开，③④ 默认关），过程记录于 docs/adr/。

## 后果

- 对比测试成本：等价轮 40 轮 ≈ 750 万 tokens；质量轮 40 轮 ≈ 1200 万 tokens
- ①② 若验收不通过 → 归因后修复或回退，不合并
- ③④ 无论质量轮结果如何都不阻塞合并（默认关闭，用户拍板后改配置）

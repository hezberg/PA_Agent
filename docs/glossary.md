# 术语表

LLM 优化分支（llm-opt）与对比测试中使用的概念定义。术语与
`pa_agent/ai/cycle_enums.py`、`prompt_engineering/市场诊断框架.txt` 对齐。

## 周期频谱八态（市场状态，按趋势强度从陡到平）

| 枚举 | 中文 | 一句话定义 |
| --- | --- | --- |
| spike | 尖峰 | 连续 2+ 根大实体趋势棒、棒间重叠 <30% 的爆发突破 |
| micro_channel | 微型通道 | 几乎无回调的单边急行 |
| tight_channel | 窄通道 | 通道态，波段回撤 <30% |
| normal_channel | 正常通道 | 通道态，波段回撤 30%~50% |
| broad_channel | 宽通道 | 通道态，波段回撤 50%~78.6% |
| trending_tr | 趋势型交易区间 | 有方向但仅 2 组波段，画不出稳定通道线 |
| trading_range | 交易区间 | 边界清晰、EMA 走平的横盘 |
| extreme_tr | 极端交易区间 | 方向丧失、EMA 纠缠、任意入场期望为负 |

## K 线窗口

- **K1**：最新一根**已收盘**K线（frame.bars 下标 0，最新优先存储）
- **K10–K1**：逐棒分析窗口——市场诊断框架要求对这 10 根做逐棒信号确认
- **K11–K100**：背景上下文——仅提供结构/波段信息，不做逐棒分析
  （本分支优化①的压缩对象）

## 冻结回放（frozen replay）

对比测试方法：预先抓取 N 支股票某周期的 K 线快照存为 JSON fixture，
两个代码分支读**同一份**数据运行分析。消除行情数据随时间漂移的问题，
使分支间差异只反映代码差异。

## 决策级等价（decision-level equivalence）

两分支分析结果的对比验收口径：

- 完全一致：`gate_result`、`cycle_position`、`order_direction`、`order_type`、置信度档位
- 容差一致：入场/止损/止盈价格 ±0.5%
- 通过线：一致率 ≥95%，不一致个案逐条人工归因

注意：深度思考开启时模型输出天然非确定，同分支跑两次文本也不同，
因此「结果不变」只能在此口径下讨论。

## 闸门（gate）

阶段一的出口判断：`proceed`（通过，进入阶段二）/ `wait`（等待，短路——程序本地
生成阶段二结果，不调模型）/ `unknown`（无法诊断，同样短路）。

## 策略路由（strategy routing）

阶段一诊断出的市场状态决定阶段二加载哪些策略文件（如「上涨通道交易策略」）。
全库 468K 字符，单轮按状态只装约 76K 字符。
